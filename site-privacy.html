This notice is about this website. Each app has its own privacy policy: Countdown Calendar and Reward Buddy.

Hosting

This site is a set of plain web pages hosted on GitHub Pages. Like any web host, GitHub's servers receive basic technical information when you visit, such as your IP address and browser type, to deliver the pages and keep them secure. GitHub handles that under its own privacy statement. We don't get a list of visitors.

Cookies and analytics

This site doesn't set cookies and doesn't use analytics, advertising, tracking pixels, scripts or embedded content from other sites. If we ever add any, we'll ask for your permission first and update this notice.

If you email us

There are no forms on this site. If you email us, we get your email address and whatever you write. We use it only to answer you, or to send the one "it's ready" note you asked for, and we delete it when we no longer need it. We don't sell it or add you to other lists.

This site is for grown-ups. Please don't let children send us their information. If a child has, tell us and we'll delete it.

Questions
