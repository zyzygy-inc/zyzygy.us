Who we are

Zyzygy is Jim Thornsberry's software company, based in Goldthwaite, in Mills County, Texas. Jim has been writing software for over 40 years, mostly in Python, C and C++.

We work the way folks do around here: say what we'll do, do it, and answer our own email.

About us

Custom software development

Need a bug fixed, a feature built, a slow program sped up, or an old system kept running? We take on remote contract work in Python, C and C++, for existing code and for well-scoped new projects.

  • Python automation and tools: scripts, internal tools, data pipelines and small integrations.
  • C and C++: libraries, tools, performance and memory work.
  • Legacy modernization: connecting older C and C++ code to modern systems.
  • Code audits, tests and CI: a plain written review, and solid tests.

Most jobs start as a fixed-price package or a weekly retainer. Contact us for a quote.
